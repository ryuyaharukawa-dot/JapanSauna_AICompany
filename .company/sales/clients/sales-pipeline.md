# 営業オペレーション管理

## 毎日のルーティン

### 問い合わせ対応フロー
1. 問い合わせ受信確認（メール・フォーム）
2. 当日〜翌日中に初回架電
3. ヒアリング（予算・用途・時期感）
4. 見積もり作成・送付
5. フォローアップ架電（3〜5営業日後）

### 見積もり作成チェックリスト
- [ ] 製品型番・サイズ確認
- [ ] オプション（ストーブ・アクセサリー）
- [ ] 設置費・送料
- [ ] 納期
- [ ] 有効期限（2週間）

## 営業仕組み化プロジェクト（C-3）

### 現状の課題
- KPIが定義されていない
- 案件のステータス管理が属人的

### 設計すべきKPI（案）
| KPI | 定義 |
|-----|------|
| 問い合わせ件数 | 週次・月次 |
| 架電接触率 | 架電数 / 問い合わせ数 |
| 見積もり提出率 | 見積もり数 / 接触数 |
| 成約率 | 成約数 / 見積もり数 |
| 平均単価 | 売上 / 成約数 |
| リードタイム | 問い合わせ〜成約の日数 |
