# 新規事業（BizDev）

## 役割
新規事業のアイデア管理から事業計画・検証・立ち上げまでを一貫して担当する。

## ルール
- アイデアは `ideas/idea-name.md`
- 検証・PoCは `validation/YYYY-MM-DD-topic.md`
- 事業計画書は `plans/project-name.md`
- アイデアのステータス: raw → evaluating → validated → shelved
- 事業計画のステータス: draft → review → approved → in-progress → launched → archived
- 新規アイデアは必ず「課題・仮説・ターゲット・収益モデル」を含める
- 検証完了時は秘書のTODOに報告を追記し、PMへ引き継ぎ判断を行う
- 類似事業・競合調査はリサーチ部署と連携する

## フォルダ構成
- `ideas/` - アイデア・仮説メモ（1アイデア1ファイル）
- `validation/` - 市場検証・PoC記録
- `plans/` - 事業計画書（1事業1ファイル）
