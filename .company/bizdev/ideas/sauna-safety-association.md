# 一般社団法人 日本サウナ安全協会（仮）

**起案日**: 2026-03-26
**ステータス**: アイデア段階

---

## 背景・きっかけ

- サウナタイガー（サウナ施設）の火災が大きなニュースになった
- 全国の消防・保健所が巡回を開始しているが、明確な基準・ルールが存在しない
- 業界全体でメンテナンスルールが未整備

## アイデアの骨格

一般社団法人を設立し、以下を担う：
1. サウナ施設のメンテナンスルール制定
2. 基準を満たした施設へのライセンス発行
3. 全国展開

JapanSaunaのブランディング強化も兼ねる。

## ビジネスモデル（想定）

| 収益源 | 内容 |
|--------|------|
| 入会費・年会費 | 施設がライセンス取得する際の費用 |
| 更新審査費 | 年次・定期審査料 |
| 研修・セミナー | 施設スタッフ向け安全講習 |
| 認定コンサル | 基準に沿った設備改修の相談 |

## JapanSaunaへの波及効果

- **ブランディング**: 基準を作った会社 = 最も信頼できる施設・販売者
- **営業**: キャビン販売時に「認定基準に準拠した製品」と訴求できる
- **The・のサウナ**: 第一号認定施設として象徴的存在に
- **SEO/PR**: 業界ニュースで名前が出やすい構造

## 課題・論点

1. **競合の先行リスク** → 他の大手施設や業界団体が先に動く可能性。スピードが重要
2. **設立コスト** → 一般社団法人の設立は10〜20万円程度。専門家費用別途
3. **基準の信頼性** → 消防・保健所との連携・お墨付きをどう取るか
4. **中立性の担保** → 商業的に見られないよう理事構成を工夫する必要あり

## 理事構成案（2026-03-26時点）

| 役職 | 担当 | 理想のプロフィール |
|------|------|----------------|
| **代表理事** | 組織の顔・対外折衝 | サウナ業界の有識者、大学教授（公衆衛生・健康科学）、元消防庁OBなど。JapanSaunaと利害関係のない人物 |
| **理事** | JapanSauna枠 | Hal（事業推進・実務） |
| **理事** | 消防・防災 | 消防士OB、防災コンサルタント、消防設備士 |
| **理事** | 建築・設備 | 一級建築士、設備設計士（サウナ施工経験あれば尚良） |
| **理事** | 医療・健康 | 医師（スポーツ医学・循環器）、温泉・入浴研究者 |
| **理事** | 施設オーナー枠 | 既存サウナ施設オーナー（大型・有名施設が望ましい） |
| **監事** | 会計・法務 | 公認会計士または弁護士 |

**代表理事候補の優先順位：**
1. 消防庁・総務省OB（行政との信頼関係が即できる）
2. 建築・設備安全の大学教授（日本建築学会・工学系防災研究室）
3. 製品安全・リスクマネジメントの専門家（製品安全協会・損保出身等）

**医療枠について：**
- 塩谷先生（サウナドクター）・加藤先生（日本サウナ学会）と繋がりあり
- 代表理事ではなく医療・健康理事として参加いただく方向で検討
- 先生方経由で代表理事候補の紹介につながる可能性もある

**構造：** 代表理事は中立的な第三者。JapanSaunaが理事＋事務局として実務を担う。

## 活動方針（骨子）

### ミッション
サウナ施設・設備のメンテナンス安全基準を策定し、基準を満たした施設・機器にライセンスを発行することで、日本のサウナ利用者が安心して使える環境をつくる。

### 3つの柱
1. **基準の制定**：サウナ機器・設備・換気・非常時対応のメンテナンス安全基準を策定・改訂
2. **ライセンス発行**：審査を通過した施設に「認定マーク」を付与。年次更新で継続的な安全担保
3. **行政連携・情報発信**：消防庁・保健所との情報共有、業界全体への安全啓発

### 会員構成（想定）
| 種別 | 対象 |
|------|------|
| 正会員 | 施設オーナー・サウナメーカー |
| 賛助会員 | 建築・消防設備・保険会社 |
| 個人会員 | 施設管理者・サウナプロ |

### 収益モデル
- 入会費・年会費
- 審査・ライセンス発行料
- 年次更新料
- 安全管理研修費

## リサーチ結果（2026-03-26）

### 既存の競合団体
- **公益社団法人 日本サウナ・スパ協会**：主に公衆浴場・大型スパ施設が対象。資格制度あり
- **日本サウナ学会**：感染症対策優良施設認定など

### 規制動向
- 消防庁が2026年3月31日施行で省令改正（テント・バレル型サウナの新防火基準）
- 個室サウナ・住宅・商業施設向けキャビンへの規制はまだ空白

### 戦略的空白
既存協会は公衆浴場・大型施設が主戦場。**個人宅・ホテル客室・一棟貸しヴィラへのサウナキャビン設置・運用基準**は未カバー。JapanSaunaの事業領域と完全一致。

### 推奨ポジション
「個人宅・商業施設向けサウナキャビンの設置・メンテナンス安全基準」を専門に扱う一般社団法人。既存協会との補完関係として連携も視野に入る。

### 社団法人設立の概要
- 費用：17〜22万円（司法書士依頼）
- 期間：最短4週間
- 最低人数：2名
- 資本金不要
